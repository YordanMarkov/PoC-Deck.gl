23 — Import Rules & Conventions

Mandatory
#RuleWhy
1 Use react-router, never react-router-dom Environment constraint; react-router-dom is not installed
2 Import Motion from 'motion/react', not 'framer-motion' Package was renamed; old import path is deprecated
3 Import toast from 'sonner', not a custom wrapper Direct import is the official pattern
4 Use re-resizable, never react-resizable react-resizable does not work in this environment
5 No useNavigate in useDeeprootNavigation.ts Causes hooks-order crash; use setSearchParams instead
6 Absolute imports use @/ prefix for src/ Consistent import paths, avoids deep relative paths
7 Logger: always import from @/app/utils/logger Single logger instance with consistent formatting
8 Supabase info from /utils/supabase/info (absolute) Special path; not an @/ alias
9 Lazy-load components >50KB or used conditionally Bundle size optimization; use lazy() + <Suspense>
10 i18n: new keys only in en.json + nl.json Fallback covers other 8 languages; batch translate later
11 Wrap every ReactFlow instance in <ReactFlowProvider> Required for hooks like useReactFlow to work
12 highlight.js: import core + individual languages only Avoids loading 180+ language grammars into the bundle
13 date-fns: centralize in dateLocalization.ts Single locale-aware formatting layer; avoids duplication
14 File size limit: <800 lines per file Extract hooks, split components, create sub-modules
